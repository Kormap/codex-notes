# test-generator

기존 프로젝트 관례에 맞춰 JUnit, Mockito, MockMvc와 통합 테스트로 회귀·경계값·동시성·실패 경로를 검증하는 스킬이다.

## 주요 산출물

- placeholder가 아닌 실제 테스트 파일
- service, controller, repository 위험에 맞는 테스트 유형
- invalid input, duplicate, 권한, 상태와 경계 날짜 테스트
- transaction·locking·동시성 통합 테스트
- 실행한 테스트 명령과 결과

실행 지침은 [SKILL.md](SKILL.md)를 확인한다.
